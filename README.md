# CSS326 Database Programming Laboratory

MySQL + Node.js (Express, `mysql2`) coursework. Dependencies are shared: run `npm install` once at this root.

| Folder | What's in it |
|---|---|
| `labs/week-NN/` | Weekly lab exercises. 01 intro · 02 database design · 03 SQL · 04 Node + MySQL · 05–06 Express apps · 09 transactions · 10 indexes, injection, least privilege · 11 stored routines, triggers, JSON, X DevAPI |
| `assignments/NN/` | Graded assignments, numbered by assignment (06 = Lab 6, 07 = Lab 9) |
| `project/` | SIIT Study Hub course project: `proposal/` (schema, diagrams, proposal) and `ui-showcase/` (HTML mockups) |
| `archive/` | `submissions/` handed-in zips, `starters/` original starter zips |

Run a week's app from its own folder, e.g. `cd labs/week-11/Lab11_Exercise_Starter && npm run dev`.
