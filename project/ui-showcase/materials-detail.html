Notes

Sorting

  • Quicksort: avg O(n log n), worst O(n²) — watch the pivot choice question, always comes up
  • Mergesort: stable, O(n log n) always, needs O(n) extra space
  • Heapsort: in-place, O(n log n), not stable

Recursion

  • Always define the base case first, then the recursive case
  • Trace with a small input by hand before trusting the code — this is literally how 3/5 exam questions are graded
  • Tail recursion doesn't get optimized in most of what we cover — don't assume it's free

Joins

  • INNER vs LEFT — draw the Venn diagram if you blank on this mid-exam
  • Know the CourseOffering example from lecture cold, it's the running example on every quiz
